# Software Testing (QA) Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for a **Software Testing (QA) Intern** to ensure the highest standards of quality, functionality, performance, and user experience across INFINEO's web applications and interactive learning platforms for children aged 5–12.

You will work closely with our engineering, product, and design teams to design comprehensive test plans, perform manual and automated functional testing, identify bugs, test cross-browser/cross-device responsiveness, and validate API endpoints to ensure a seamless and child-friendly digital experience.

## What You'll Do

- Execute manual and automated test cases across web applications, interactive modules, and backend APIs
- Perform functional, regression, sanity, and UI/UX responsiveness testing across various browsers, screen sizes, and mobile devices
- Create clear, detailed, and structured test plans, test suites, and bug reports with reproducible steps and screenshots/recordings
- Test RESTful APIs and backend integration flows using tools like Postman
- Collaborate with frontend and backend developers to debug issues, track bug lifecycles, and verify fixes in agile sprints
- Identify performance bottlenecks, usability glitches, and edge cases to ensure optimal experience for young learners
- Leverage AI-powered QA and testing tools (such as ChatGPT, Claude, Cursor, or automated testing agents) to generate test cases and optimize testing workflows

## What We're Looking For

- Solid understanding of **Software QA concepts, testing methodologies (STLC/SDLC)**, test case creation, and bug lifecycle management
- Strong attention to detail and ability to identify subtle UI/UX glitches, functional anomalies, and edge cases
- Familiarity with API testing concepts and tools like **Postman**
- Understanding of web technologies (HTML, CSS, JavaScript) to effectively inspect elements and diagnose client-side issues
- Excellent analytical, problem-solving, and communication skills to document and report bugs effectively
- Proactive mindset and enthusiasm for maintaining high product quality

### Good to Have

- Basic knowledge of automated testing frameworks (e.g., **Selenium, Cypress, Playwright, or Jest**)
- Exposure to project management / bug tracking tools (such as Jira, Trello, or GitHub Issues)
- Basic understanding of performance and load testing concepts
- Interest in EdTech platforms, gamified web interfaces, and child-friendly UX testing

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Hands-on experience testing and validating live features for a high-impact EdTech platform
- Exposure to modern QA methodologies, automated testing frameworks, and AI-assisted QA workflows
- Opportunity to contribute directly to product stability and user experience for children and educators
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements
