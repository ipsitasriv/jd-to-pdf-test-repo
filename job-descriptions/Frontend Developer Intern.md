# Frontend Developer Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for a **Frontend Developer Intern** to build responsive, visually engaging, and high-performance web applications and interactive learning interfaces for children aged 5–12 at INFINEO.

You will work on building component libraries, translating Figma designs into fluid UI components using React and Next.js, optimizing client-side performance, and integrating APIs to deliver seamless web experiences.

## What You'll Do

- Develop, test, and maintain modern frontend web applications and interactive components using React, Next.js, and TypeScript/JavaScript
- Convert Figma wireframes and UI designs into pixel-perfect, responsive web layouts across desktop and mobile devices
- Implement state management, dynamic UI rendering, and seamless client-side interactions
- Connect frontend components with RESTful APIs and backend services
- Optimize web application performance, accessibility, rendering speed, and cross-browser compatibility
- Leverage AI coding assistants to accelerate frontend development workflows

## What We're Looking For

- Strong proficiency in **HTML, CSS, JavaScript, and React.js / Next.js**
- Experience with modern CSS frameworks
- Solid understanding of DOM manipulation, component lifecycle, props/state management, and responsive web design
- Ability to write clean, modular, maintainable code with sharp attention to UI/UX detail
- Proactive problem-solving mindset and eagerness to iterate based on code reviews

### Good to Have

- Experience with **TypeScript** and state management libraries
- Familiarity with animation libraries
- Exposure to AI code generation tools
- Interest in EdTech products, gamified web interfaces, or child-friendly UX design

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Hands-on experience building production frontend features for an active EdTech platform
- Direct exposure to modern frontend tech stacks, component design systems, and AI-assisted workflows
- Opportunity to build interactive web experiences used by children and educators
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements
