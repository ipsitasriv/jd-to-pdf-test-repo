# Full Stack Developer Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for a versatile **Full Stack Developer Intern** to build end-to-end web features, from user-facing frontend interfaces to robust backend API architecture and database models at INFINEO.

You will work across the entire technology stack—developing responsive UI components in React/Next.js, designing server-side API logic in Node.js or Python, managing database pipelines, and connecting AI services to deliver end-to-end product features.

## What You'll Do

- Build and deploy full-stack web applications and feature modules across frontend and backend layers
- Develop responsive frontend UI components using React, Next.js, and Tailwind CSS
- Architect server-side REST APIs, database schemas, and data pipelines using Node.js or Python
- Connect client applications with backend databases (PostgreSQL/MongoDB) and external AI services (OpenAI, Claude, Gemini)
- Handle end-to-end feature lifecycle: requirements → UI development → backend integration → testing → deployment
- Optimize application performance, resolve full-stack bugs, and ensure seamless user experiences across devices

## What We're Looking For

- Proficiency across frontend technologies (**HTML, CSS, JavaScript, React/Next.js**) and backend stacks (**Node.js/Express or Python**)
- Experience working with relational or NoSQL databases (**PostgreSQL, MongoDB**)
- Clear understanding of REST APIs, HTTP, authentication protocols, and state management
- Strong problem-solving skills with the ability to navigate full-stack debugging and feature integration
- High ownership mindset, adaptability, and speed of technical execution

### Good to Have

- Experience with **TypeScript, Tailwind CSS, Prisma/SQLAlchemy**, or Next.js App Router
- Exposure to cloud hosting platforms (Vercel, AWS, Render) and Docker containerization
- Experience building AI-enabled applications or integrating LLM APIs into web apps
- Familiarity with AI coding tools

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Comprehensive 360° software engineering experience across the full production stack
- Exposure to modern full-stack workflows, AI API integrations, and cloud deployment pipelines
- Direct impact building user-facing product features used by children and educators
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements
