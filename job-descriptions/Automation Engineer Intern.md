# Automation Engineer Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for an **Automation Engineer Intern** to design, build, and maintain robust automated testing frameworks, CI/CD pipelines, and workflow automation scripts across INFINEO's digital platforms and educational applications for children aged 5–12.

You will work closely with our engineering, QA, and product teams to automate end-to-end user journeys, API testing workflows, regression test suites, and internal developer tooling using modern automation frameworks and AI-assisted tooling.

## What You'll Do

- Design, develop, and execute automated test scripts for web applications, user interfaces, and backend APIs using tools like Selenium, Playwright, Cypress, or Puppeteer
- Build and maintain automated API testing pipelines using Postman / Newman, REST-assured, or Python/JavaScript scripts
- Integrate test automation suites into CI/CD pipelines (such as GitHub Actions) for continuous testing and automated build verification
- Identify, document, track, and report defects with detailed logs, execution traces, and root cause analysis
- Develop automated scripts and internal bots for data scraping, workflow automation, and routine operational tasks
- Collaborate with developers and QA engineers to increase automated test coverage and reduce manual testing overhead
- Leverage AI-powered automation and coding assistants (Cursor, GitHub Copilot, ChatGPT, Claude) to accelerate test script development and maintenance

## What We're Looking For

- Foundational programming skills in **Python, JavaScript/TypeScript, or Java**
- Solid understanding of **test automation concepts, frameworks, and design patterns (such as Page Object Model)**
- Familiarity with web automation tools such as **Selenium, Playwright, Cypress, or Puppeteer**
- Understanding of REST APIs, HTTP protocols, and automated API testing concepts
- Strong analytical and debugging skills with sharp attention to detail
- Self-motivated mindset with eagerness to learn modern automation tools and best practices

### Good to Have

- Familiarity with **CI/CD tools (GitHub Actions)** and version control with **Git**
- Basic knowledge of testing frameworks (PyTest, Jest, Mocha)
- Experience with web scraping libraries (BeautifulSoup, Scrapy) or workflow automation tools (n8n, Zapier, Python scripts)
- Basic understanding of performance/load testing tools (JMeter, k6, Locust)
- Interest in EdTech platforms, interactive web experiences, and child-friendly UX testing

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Real-world experience architecting test automation suites and CI/CD pipelines for production applications
- Direct exposure to modern automation tools, API validation frameworks, and AI-assisted workflows
- Opportunity to build quality engineering infrastructure for platforms used by children and educators
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements
