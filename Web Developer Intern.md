# Web Developer Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for a **Web Developer Intern** to build, optimize, and maintain responsive web platforms, landing pages, and interactive frontend interfaces at INFINEO.

You will work on translating UI/UX designs into functional web applications using HTML, CSS, JavaScript, and modern frameworks (React/Next.js), optimizing web performance, fixing UI bugs across devices, and leveraging AI coding assistants to accelerate development speed.

## What You'll Do

- Build, refine, and deploy responsive web pages, landing experiences, and reusable frontend UI components
- Convert wireframes, Figma designs, and product concepts into clean, functional HTML, CSS, and JavaScript code
- Optimize frontend performance, ensure mobile responsiveness, and debug cross-browser compatibility issues
- Leverage AI coding tools to speed up development workflows
- Conduct cross-device QA testing, troubleshoot bugs, and iterate on web features based on team feedback
- Maintain clean, organized codebase structures and follow web accessibility and UI standards

## What We're Looking For

- Fundamental proficiency in **HTML, CSS, and JavaScript**
- Ability to write clean, modular, and mobile-responsive webpage layouts
- Strong analytical problem-solving mindset and sharp attention to UI code organization
- Ability to work independently, troubleshoot technical issues, and iterate based on code reviews
- Deep curiosity about web technologies, frontend frameworks, and digital product building

### Good to Have

- Experience with modern frontend frameworks/libraries (**React, Next.js, or Tailwind CSS**)
- Basic understanding of REST APIs, client-server communication, or backend integration
- Experience using AI code generation tools
- Interest in UI/UX design principles, web accessibility, or EdTech platforms

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Hands-on experience building production features for live EdTech websites and platforms
- Exposure to modern web development workflows, component architectures, and AI-assisted engineering
- Opportunity to directly build web applications used by children and educators
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements
