# Game Developer Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for a **Game Developer Intern** to build simple, interactive browser-based games and learning activities for children aged 5–12 at INFINEO.

You will work on converting story concepts, moral frameworks, and learning challenges into engaging, interactive formats using AI-assisted code generation (HTML/CSS/JavaScript), writing and refining prompts, and building fun, educational game mechanics.

## What You'll Do

- Build simple, interactive browser-based games and mini-activities using AI tools and code generation
- Convert story concepts, moral dilemmas, and learning scenarios into interactive formats (e.g., choice-based scenarios, decision trees, puzzles)
- Write, test, and refine prompts to generate clean HTML, CSS, and JavaScript game logic and UI components
- Test game mechanics across browsers, debug outputs, and iterate to ensure smooth, responsive gameplay
- Collaborate with curriculum and creative teams to align game objectives with learning takeaways
- Review game outputs for visual appeal, intuitive user experience, and logical flow

## What We're Looking For

- Strong logical, structured problem-solving mindset
- Deep curiosity about how web applications, interactive media, and digital games work
- Basic understanding of logical flows, conditional structures, and user interaction
- Ability to experiment with AI tools, iterate rapidly, and troubleshoot game outputs
- High attention to detail and commitment to functional, smooth user experiences

### Good to Have

- Experience using AI code/design generation tools
- Basic exposure to HTML, CSS, or JavaScript concepts
- Interest in game design, interactive storytelling, or educational technology (EdTech)

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Hands-on experience in building digital products using AI-assisted web development workflows
- Exposure to educational game mechanics, interactive storytelling, and rapid prototyping
- Opportunity to work on interactive games used in children's learning
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements

INFINEO is a character-building platform for children aged 5–12. We connect the wisdom of Indian mythology with real-world challenges to create engaging, story-driven experiences that help children develop confidence, empathy, resilience, critical thinking, and better decision-making.
