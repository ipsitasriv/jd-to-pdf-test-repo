# Backend Developer Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for a **Backend Developer Intern** to design, build, and maintain scalable server-side systems, database architectures, and API pipelines that power INFINEO's digital platforms.

You will work on developing RESTful APIs, managing relational and NoSQL databases, implementing authentication and security protocols, and integrating third-party AI services to support backend data flows.

## What You'll Do

- Architect, build, and maintain scalable server-side applications and microservices using Node.js or Python
- Design and optimize relational and NoSQL database schemas
- Develop clean, secure, and well-documented RESTful APIs and WebSocket connections for frontend platforms
- Implement user authentication, authorization protocols (JWT, OAuth), data validation, and security best practices
- Integrate external AI model APIs (OpenAI, Anthropic, Gemini), cloud services, and third-party webhooks
- Debug server-side performance bottlenecks, conduct API testing, and monitor database query efficiency

## What We're Looking For

- Fundamental knowledge of backend programming in **Node.js (Express/NestJS)** or **Python (FastAPI/Django/Flask)**
- Good understanding of database management systems and ORM tools
- Solid understanding of REST API principles, HTTP protocols, asynchronous programming, and JSON handling
- Problem-solving mindset with attention to code structure, security, and scalability
- Ability to write clean, maintainable backend code and iterate based on code reviews

### Good to Have

- Experience with **Docker, caching, CI/CD pipelines**, or cloud infrastructure (AWS / GCP / Vercel)
- Exposure to WebSockets, serverless functions, or microservices architecture
- Experience integrating AI LLM APIs (OpenAI, Claude, Gemini) into backend servers
- Familiarity with backend testing tools (Jest, PyTest, Postman)

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Real-world experience building scalable backend architectures and API infrastructure
- Hands-on exposure to cloud deployment, database optimization, and AI service integration
- Opportunity to build backend systems powering platform content for thousands of children
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements
