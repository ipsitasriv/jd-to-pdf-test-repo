# Python Developer Intern

**Remote | 4 Months | 6 Hours/Day, 6 Days/Week | Unpaid Internship**

## About the Role

We are looking for a **Python Developer Intern** to build backend APIs, data processing pipelines, automation scripts, and AI-driven backend services at INFINEO.

You will work on writing clean Python code, developing REST APIs using FastAPI/Flask/Django, building web scrapers and data automation tools, and integrating AI model APIs into internal workflows.

## What You'll Do

- Develop, test, and maintain backend APIs and web services using Python frameworks (**FastAPI, Flask, or Django**)
- Build automated scripts for data processing, web scraping, file manipulation, and workflow automation
- Connect Python backend services with databases (PostgreSQL, SQLite, MongoDB) using ORM tools
- Integrate third-party APIs, AI services (OpenAI, Claude, Gemini), and cloud services into Python applications
- Write unit tests, debug server-side logic, and optimize script execution efficiency and data processing speed
- Document API endpoints, script logic, and technical workflows for team collaboration

## What We're Looking For

- Strong foundational skills in **Python programming** (data structures, OOP, file handling, async/await, error handling)
- Basic understanding of web development and REST API concepts using frameworks like **FastAPI, Flask, or Django**
- Analytical problem-solving ability with sharp attention to code readability and efficiency
- Willingness to learn new packages, frameworks, and backend technologies quickly

### Good to Have

- Experience with data manipulation libraries (**Pandas, NumPy**) or web scraping tools (**BeautifulSoup, Scrapy, Selenium**)
- Good understanding of relational databases (**PostgreSQL, MySQL, or SQLite**) and basic SQL queries
- Experience integrating AI LLM APIs (OpenAI, Anthropic) or building CLI tools in Python
- Familiarity with **Docker, Git, Postman**, or cloud deployment platforms

## What You'll Get

- Certificate of Internship
- Letter of Recommendation (LOR), based on performance
- LinkedIn Recommendation, based on performance
- Real-world experience writing production Python code and backend automation tools
- Exposure to AI integration, backend database architecture, and software engineering best practices
- Opportunity to build backend infrastructure powering innovative edtech tools
- High-performing interns may be considered for future full-time opportunities based on performance and business requirements
